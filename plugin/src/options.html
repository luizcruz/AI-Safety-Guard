Baixar servidor MCP

A configuração exporta as categorias e políticas atuais. Baixe-a novamente após alterá-las.

Preparação comum

  1. Instale o Node.js 18 ou superior.
  2. Baixe os dois arquivos acima.
  3. No PowerShell, mova-os para uma pasta permanente:
New-Item -ItemType Directory -Force "$HOME\.ai-safety-guard"
Move-Item "$HOME\Downloads\ai-safety-mcp.cjs" "$HOME\.ai-safety-guard\ai-safety-mcp.cjs" -Force
Move-Item "$HOME\Downloads\config.json" "$HOME\.ai-safety-guard\config.json" -Force

Se o navegador salvar em outra pasta, ajuste a origem. Nos comandos abaixo, substitua SEU_USUARIO pelo seu usuário do Windows.

Claude Code

  1. Adicione e valide o servidor:
claude mcp add --scope user ai-safety-guard -- node "C:/Users/SEU_USUARIO/.ai-safety-guard/ai-safety-mcp.cjs"
claude mcp list
  1. Mescle em ~/.claude/settings.json:
{
  "hooks": {
    "UserPromptSubmit": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "node \"C:/Users/SEU_USUARIO/.ai-safety-guard/ai-safety-mcp.cjs\" --hook",
            "timeout": 15
          }
        ]
      }
    ]
  }
}
  1. Reinicie o Claude Code e execute /hooks e /mcp. Para desabilitar, remova o bloco UserPromptSubmit e execute:
claude mcp remove ai-safety-guard

ChatGPT Codex

  1. Adicione e valide o servidor:
codex mcp add ai-safety-guard -- node "C:/Users/SEU_USUARIO/.ai-safety-guard/ai-safety-mcp.cjs"
codex mcp list
  1. Mescle em ~/.codex/hooks.json:
{
  "hooks": {
    "UserPromptSubmit": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "node \"C:/Users/SEU_USUARIO/.ai-safety-guard/ai-safety-mcp.cjs\" --hook",
            "timeout": 15
          }
        ]
      }
    ]
  }
}
  1. Reinicie o Codex, execute /hooks, revise e confie no hook. Para desabilitar, remova o bloco UserPromptSubmit e execute:
codex mcp remove ai-safety-guard
